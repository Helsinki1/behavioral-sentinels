# NewInML paper graphs

This folder contains the four readable PNG figures selected for the NewInML
2026 workshop draft. The prior dense composites and individual precision–recall
panels were removed.

- `01-recovery-operator-effects.png`: lossy compaction and public-state
  regrounding relative to monitored no-action, by monitoring method.
- `02-active-probe-observer-effect.png`: retained powered observer-effect and
  exploratory mechanism figure.
- `03-signal-quality-auprc.png`: all seven model-by-task slices and all eight
  monitoring methods in one AUPRC heatmap.
- `04-observation-overhead.png`: observer tokens and recorded cost by method.

The three new figures are generated by
`../scripts/posthoc/build_workshop_figures12.py` from frozen derived summaries.
The script is provider-free and cannot rerun agent traces. Reproducible SVG
sources and a hash receipt are under
`../data_results/derived/workshop-figures12/`.
