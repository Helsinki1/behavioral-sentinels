# Data and results

- `inputs/`: frozen model catalog, task allocations, screening receipts, and external-source instructions.
- `runs/`: raw run manifests, ledgers, events, trajectories, monitor outputs, and run-local results.
- `derived/`: composed datasets, audits, tables, paper summaries, and source SVG figures.

For a fast paper-level view, open `derived/PAPER_MATERIALS12.md`. For final
raster figures, use `../graphs/`.

Frozen historical files are not rewritten: some contain their original
`experiments12/artifacts` or `experiments12/generated` paths as provenance.
`RELOCATION_MAP.json` records the new physical locations.
